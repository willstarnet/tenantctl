# Getting help

- **How do I ...?** Check the [README](README.md), `tenantctl <area> --help` and
  [docs/domains](docs/domains), then open a
  [question](https://github.com/willstarnet/tenantctl/issues/new?template=question.md).
- **Something is broken.** Open a
  [bug report](https://github.com/willstarnet/tenantctl/issues/new?template=bug_report.md) with the
  tenantctl version, your OS and the command. Remove tenant names, user names, email addresses,
  device names and ids from output you paste.
- **An idea.** Open a
  [feature request](https://github.com/willstarnet/tenantctl/issues/new?template=feature_request.md).
- **Security.** Privately, as [SECURITY.md](SECURITY.md) describes.
- **Microsoft 365 itself** (an outage, a Graph API bug, licensing): `tenantctl health overview`, then
  Microsoft support.
