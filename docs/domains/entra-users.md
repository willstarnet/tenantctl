# Entra ID: users

User lifecycle and per-user troubleshooting: `tenantctl entra users ...`. Groups, directory-wide sign-ins, audit,
roles, apps, Conditional Access and risk are in the directory commands (`tenantctl entra --help`).

Every `<user>` accepts a UPN, email address or alias, display name, object id, or `me`. A name that matches
several people returns `AMBIGUOUS` with the candidates.

## Common tasks

| Admin intent                                                               | Command                                                                                                                                                                                                                                                                                                          |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Find a user                                                                | `tenantctl entra users list --search jane`                                                                                                                                                                                                                                                                       |
| Who is disabled / a guest / in a department                                | `tenantctl entra users list --disabled`, `--guests`, `--department Sales`                                                                                                                                                                                                                                        |
| Who has no license                                                         | `tenantctl entra users list --unlicensed --all`                                                                                                                                                                                                                                                                  |
| Who hasn't signed in for 90 days                                           | `tenantctl entra users list --inactive-days 90 --all`                                                                                                                                                                                                                                                            |
| Everything about one person (state, sync, manager, licenses, last sign-in) | `tenantctl entra users get jane@contoso.com`                                                                                                                                                                                                                                                                     |
| "Jane can't sign in"                                                       | `tenantctl entra users get jane@contoso.com`, then `tenantctl entra users signins jane@contoso.com --failures-only`                                                                                                                                                                                              |
| "Jane isn't getting MFA prompts / got a new phone"                         | `tenantctl entra users auth-methods jane@contoso.com`, `tenantctl entra users auth-method remove jane@contoso.com <methodId>`, `tenantctl entra users tap jane@contoso.com`                                                                                                                                      |
| "Why doesn't Jane have Teams?"                                             | `tenantctl entra users licenses jane@contoso.com`                                                                                                                                                                                                                                                                |
| Which groups / admin roles is Jane in                                      | `tenantctl entra users groups jane@contoso.com --all`                                                                                                                                                                                                                                                            |
| Jane's devices as Entra / Conditional Access sees them                     | `tenantctl entra users devices jane@contoso.com`                                                                                                                                                                                                                                                                 |
| New starter                                                                | `tenantctl entra users create --display-name "Jane Doe" --upn jane@contoso.com --usage-location US --manager bob@contoso.com`, then `tenantctl entra users license add jane@contoso.com --sku SPE_E3`                                                                                                            |
| Many new starters at once                                                  | `tenantctl --dry-run entra users bulk-create starters.csv` (validates every row, creates nothing), then `tenantctl entra users bulk-create starters.csv`; columns DisplayName, UserPrincipalName, optional MailNickname, Password, UsageLocation, Department, JobTitle, Manager, License, Groups (`;`-separated) |
| Invite an external guest (B2B)                                             | `tenantctl entra users invite pat@fabrikam.com --name "Pat Partner" --group "Project X"` (`--no-email` to share `inviteRedeemUrl` yourself)                                                                                                                                                                      |
| Change title, department, phone, manager, usage location                   | `tenantctl entra users update jane@contoso.com --job-title "Lead" --manager bob@contoso.com`                                                                                                                                                                                                                     |
| Reset a password                                                           | `tenantctl entra users reset-password jane@contoso.com` (returns the temporary password once)                                                                                                                                                                                                                    |
| Offboard / compromised account                                             | `tenantctl entra users disable jane@contoso.com`, then `tenantctl entra users revoke-sessions jane@contoso.com`                                                                                                                                                                                                  |
| Sign someone out everywhere (lost device)                                  | `tenantctl entra users revoke-sessions jane@contoso.com`                                                                                                                                                                                                                                                         |
| Assign or remove a license                                                 | `tenantctl entra users license add jane@contoso.com --sku SPE_E3 --disable-plans SWAY`, `tenantctl entra users license remove jane@contoso.com --sku SPE_E3`                                                                                                                                                     |
| Delete / undo a delete                                                     | `tenantctl entra users delete jane@contoso.com`, `tenantctl entra users deleted`, `tenantctl entra users restore <id>`                                                                                                                                                                                           |

`disable`, `reset-password`, `revoke-sessions`, `delete`, `tap`, `auth-method remove` and `license remove` are
destructive: they show a preview of the user and the change and run only once you approve it.

## Licensing and roles

| Feature                                                  | Needs                                                                                                                                                                        |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Last sign-in (`users get`, `users list --inactive-days`) | Entra ID P1/P2, `AuditLog.Read.All`                                                                                                                                          |
| Sign-in logs (`users signins`)                           | Entra ID P1/P2 for 30 days of history (7 days on free), `AuditLog.Read.All`; role Reports Reader, Security Reader or Global Reader                                           |
| MFA registration summary (`users auth-methods`)          | Entra ID P1/P2, `AuditLog.Read.All`                                                                                                                                          |
| Read auth methods                                        | Authentication Administrator, Privileged Authentication Administrator or Global Reader (phone numbers are masked for Authentication Administrators)                          |
| Remove methods, issue TAP                                | Authentication Administrator (non-admin users) or Privileged Authentication Administrator (anyone); TAP must be enabled in the authentication methods policy                 |
| Reset password                                           | Helpdesk Administrator (non-admins), User Administrator, Privileged Authentication Administrator (anyone); `User-PasswordProfile.ReadWrite.All`                              |
| Enable / disable                                         | User Administrator, Authentication Administrator, Privileged Authentication Administrator; `User.EnableDisableAccount.All` + `User.Read.All`                                 |
| Create, update, delete, restore                          | User Administrator                                                                                                                                                           |
| Invite guests                                            | Guest Inviter or User Administrator (or any member if guest invitations are not restricted); `User.Invite.All`; blocked when external collaboration settings deny the domain |
| Bulk create (`users bulk-create`)                        | User Administrator; `User.ReadWrite.All` (manager), `LicenseAssignment.ReadWrite.All`, `GroupMember.ReadWrite.All`                                                           |
| Assign licenses                                          | License Administrator or User Administrator; the user needs a usage location                                                                                                 |
| `users devices`                                          | Delegated sign-in only (Graph has no application permission for owned/registered devices)                                                                                    |

When signing in as an app (client credentials), password resets and changes to admin accounts also need an Entra
admin role assigned to the app's service principal.

Synced users (`isSynced: true`) are mastered in on-premises Active Directory: name, enabled state and password
must be changed in AD (password resets via Graph need password writeback).

## Not available via Graph

| Task                                                                        | Use instead                                                                                                 |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Per-user (legacy) MFA state: enable/enforce/disable                         | Entra admin center (per-user MFA page) or the beta `authentication/requirements` endpoint, not wrapped here |
| "Require re-register MFA" button                                            | Remove each method with `users auth-method remove`, then `users tap`                                        |
| Unlock a Smart Lockout lockout                                              | Wait for the lockout to expire, or reset the password                                                       |
| Change a synced user's attributes or password without writeback             | On-premises AD (ADUC / PowerShell), then Entra Connect sync                                                 |
| Mailbox actions on leavers (convert to shared, forwarding, litigation hold) | `tenantctl exchange` commands or Exchange Online PowerShell                                                 |
| OneDrive access for a leaver's manager                                      | `tenantctl sharepoint` commands or SharePoint Online admin center                                           |
| Permanently purge a soft-deleted user before 30 days                        | `DELETE /directory/deletedItems/{id}` via `tenantctl graph delete` (irreversible)                           |
| Add a hardware OATH token (beta-only API)                                   | Entra admin center                                                                                          |
| See eligible (PIM) roles                                                    | `tenantctl entra` role commands or Entra admin center; `users groups` shows active roles only               |
